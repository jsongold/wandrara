必須の項目

コア必須の列details の必須（quality.ts）今の決まりからの変更
建物地域・位置時間（hours）・料金 1 つ以上（無料は 0）hours を 1 つ（配列でなく）に。料金に audience
日帰り温泉地域・位置時間・大人の料金・泉質のある風呂 1 つ以上hours を 1 つに。風呂の種類を宿と同じ語彙に（sauna を足す）
まち地域・位置行き方（access）access を 1 つ（配列でなく）に

体験・自然と同じく、列を足して先に本番に当てる → コードを出す → 集め直す → 旧い表を消す、の順に進める。

画面の並び

建物

「開館・入館」の 1 行 → 時間（休み）→ 料金 → 催し → アクセス（地図）→ 注意点 → 出典

日帰り温泉

「営業・大人の料金」の 1 行 → 風呂（泉質）→ 料金 → 時間（休み）→ 設備 → アクセス（地図）→ 注意点 → 出典

まち

「歩く時間・店の時間」の 1 行 → 歩き方 → 店の時間 → 催し → アクセス（地図）→ 注意点 → 出典
