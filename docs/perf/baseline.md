# 計測の基準値（MS0）

目的：表示の速さと通信量の基準値を残し、各 MS の効果を同じ条件で比べられるようにする。

- 計測日：2026-11-19（JST）。計測コマンド：`pnpm perf`（`scripts/perf/measure.ts`）。生データ：`baseline-prod.json`・`baseline-local.json`。
- 数値は 3 回の中央値（括弧は最小〜最大）。KB は転送バイト（圧縮後）÷ 1024。

## 1. 発足時の暫定の基準値（2026-11-19、MS1 より前の本番）

### 分かったこと

## 4. 記録した環境とデータ

- 実行地点：手元の Mac（日本）から。Vercel の edge は `kix1`（`x-vercel-id`）。関数の region は `vercel.json` の `hnd1`（東京）。Supabase の region は未確認。
- データ件数（anon から読める公開分）：`dest_cards` 560・`regions` 1,990・`dest_photos` 3,272。`/ja` の document に入っているカードは 194 枚。
- 回線：Slow 4G は下り 1.6Mbps・上り 0.75Mbps・RTT 150ms（CDP の `Network.emulateNetworkConditions`）。CPU 4x は `Emulation.setCPUThrottlingRate`。
- Save-Data：リクエストヘッダ `Save-Data: on` と `navigator.connection.saveData = true` を付ける再現。Chromium でデータセーバーの本物の設定は自動化できない。
- 状態：ブラウザキャッシュは「初回 = 空の context」「2 回目 = 同じ context で再訪」。サーバー・画像 CDN は、計測前に 1 回訪問して温めた状態（`PERF_WARMUP=0` で冷たい状態も測れる。今回は未計測）。本番の document は `x-vercel-cache: HIT`。

- ログイン時の Supabase 宛リクエスト数：未測。未ログインは 0。
- 海外からの計測：未取得（手元の Mac からのみ）。
- Supabase の region。
- スクロールの途中の節目や、カタログが 2 倍・5 倍になったときの値（MS2b・MS5 で測る）。

### 海外のエミュレーション（実測ではない）

**手元の Mac から CDP で RTT 200ms・下り 3Mbps・CPU 絞りなしにしたもの。実際の海外の利用者の計測ではない**（edge は日本の `kix1` のまま、関数は `hnd1`）。

初回 612KB・TTFB 0.24s・最初のカード 0.71s・LCP 1.91s（1.84〜1.98）。10 枚スクロール込み 996KB。2 回目 33KB（最悪 55KB）・最初のカード 0.36s。詳細 0.05s。Save-Data 432KB（最初のカード 0.70s・LCP 1.31s）。RTT の増加は、往復の数が少ない（JS 230KB・document 13KB・画像 6 枚）ので表示にあまり響かない。

### 最初の 1 回（`PERF_WARMUP=0`、制限なし）

デプロイの約 7 分後（16:04 JST）。この前にスモーク確認（`/ja`・`/api/feed`・エリア・詳細・Save-Data の詳細）で関数と CDN が温まっていたため、「デプロイ直後の本物の cold」ではない。初回 612KB・TTFB 0.08s・最初のカード 0.31s・LCP 0.38s で、前に見た外れ値（デプロイ直後の遅い 1 回）は再現しなかった。

### 2 回目の訪問が 50KB を超える原因（確認済み）

`pnpm perf` の遅い条件では 2 回目が 55KB（制限なしは 34KB）。2 回目の訪問が 1 回目から 60 秒以上あくと、`/api/area-sheet`（約 23KB、`max-age=60`）が取り直される。60 秒空けて手動で再訪した確認：合計 57.7KB のうち `/api/area-sheet` 23.0KB・document 12.9KB・詳細の先読み RSC など。実際の再訪は 60 秒より空くので、こちらが実態に近い。MS2c の 33KB は、60 秒以内に再訪した計測だった。

対応（#143）：`/api/area-sheet` に ETag を付け、60 秒が切れた再訪は 304 にした。`PERF_REPEAT_DELAY_MS=65000 pnpm perf` で再訪の前に 65 秒待てる。ローカルの本番ビルドでは 2 回目が 76KB から 55KB（-21KB。area-sheet が 304）。本番の値はデプロイ後に測る（`docs/perf/README.md` 6 節）。
